### Introduction

A mobile component library built for React, inspired by [Vant](https://vant-contrib.gitee.io/vant/v3/#/zh-CN).

### Features

- 50+ high-quality components covering various mobile scenarios
- Excellent performance with average component size less than 1kb (min+gzip)
- Unit test coverage over 95%, ensuring stability
- Complete documentation and examples
- Support for on-demand import
- Support for theme customization
- Support for TypeScript

### Quickstart

Please refer to the [Quickstart](#/en-US/quickstart) section.

### Browser Support

Supports modern browsers and Chrome >= 51, iOS >= 10.0
